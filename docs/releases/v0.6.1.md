First public beta of Redux Better AA. It adds TAA, NVIDIA DLAA and FSR 2 Native AA
to KSP2 Redux, alongside FXAA, SMAA and supersampling. Temporal AA runs before
the UI, and physics is unchanged.

Download **ReduxBetterAA-0.6.1.zip** below and extract it beside `KSP2_x64.exe`.
Choose a mode under **Settings → Mods → Redux Better AA**. Redux 0.2.8.5 and
0.2.9.0 on Windows x64 are supported. Better Clouds is optional.

For DLAA or FSR 2, also download the runtime ZIP matching your Redux version:
[0.2.9.0](https://github.com/Michionlion/ReduxBetterAA/releases/download/v0.6.1/BetterAA-Runtimes-Redux-0.2.9.0.zip)
or [0.2.8.5](https://github.com/Michionlion/ReduxBetterAA/releases/download/v0.6.1/BetterAA-Runtimes-Redux-0.2.8.5.zip).
Extract it beside `KSP2_x64.exe`. Each ZIP contains three DLLs and their notices.

The launchpad hills now use depth that matches temporal jitter. That cut the
measured terrain flicker signal by 94–97% across TAA, DLAA and FSR 2 in the test
view, without reducing their sample coverage or quality settings. The fix added
about 0.003 ms of CPU work per depth draw and allocated no managed memory in
the measured draws. Testing used Redux 0.2.9.0, D3D11 and an RTX 5070 Ti at 1440p;
GPU pass timings weren't available.

Still a beta: other GPUs and more flight/VAB scenes need testing. Map AA uses
zero jitter. Stop F10's live comparison before judging terrain flicker; it uses
a separate rendering path. There is no DLSS upscaling or frame generation.

For bugs, **F10 → Issue ZIP** collects screenshots and renderer information.
Review it before attaching it to an issue; nothing is uploaded automatically.
