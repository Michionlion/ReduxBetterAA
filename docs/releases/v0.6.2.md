Beta release adding DLSS/FSR upscaling, modern FSR native AA and independent frame generation, with fixes for vessel/terrain motion and distant water flicker.

Download **ReduxBetterAA-0.6.2.zip** and extract beside `KSP2_x64.exe` with the game closed. Preserve your configuration and reports when updating. New installs default to TAA; saved selections are preserved.

- **Frame generation** is one separate setting: Off, Auto, supported DLSS 2x-4x and FSR 4/3.1 2x options. It works with TAA, DLAA, FSR Native AA and supported upscaling modes. Capability probes control the choices; unsupported DLSS multipliers fall back through lower supported multipliers, then FSR 2x. FSR 4 falls back to 3.1. FG defaults to Off.
- DLSS and FSR upscaling offer Quality, Balanced and Performance. Modern FSR replaces the legacy Unity FSR 2 backend, selecting FSR 4.1 or its 3.1 compatibility provider through the SDK.
- Terrain motion repair accounts for moving planet geometry while preserving foreground vessel motion. Flight/KSC transparent rendering now uses the same jitter as the temporal scene, fixing the tested distant coastline/water flicker without another setting or render pass.
- Frame-generation capture, synchronization, presentation ownership and timeout handling are guarded; unsupported scenes return to ordinary rendering. Diagnostics include the requested/active provider and input state.

Optional downloads, extracted beside `KSP2_x64.exe`:

- For FSR native AA/upscaling: **BetterAA-FSR-Runtime-0.6.2-win-x64.zip**.
- For frame generation: **BetterAA-FrameGeneration-0.6.2-Redux-0.2.9.0-amd-nvidia-win-x64.zip**. This is separate from the AA/upscaler runtimes.
- For NVIDIA DLAA/DLSS: the NVIDIA runtime ZIP matching your Redux version, linked below.

Validation used Redux 0.2.9.0, Unity 6000.5.8f1, D3D11, an RTX 5070 Ti and 1440p. All 366 EditMode tests and portable release/package checks passed on the candidate. Limited player runs exercised AA/upscaling, DLSS 2x-4x, FSR 3.1 FG 2x, provider switching and Off/re-enable. In the matched north-facing ascent view, the final water fix reduced the measured DLAA shoreline temporal residual by about 92%; the user reported no visible flicker in the TAA, DLAA and FSR runs. These measurements describe that fixture, not all scenes.

Still a beta: AMD FSR 4/FG 4 and older RTX hardware need hardware validation. Broad moving-image quality, displayed cadence, latency, long sessions and device-loss recovery remain incomplete. FG requires the inspected Redux 0.2.9.0 D3D11 player, windowed/borderless SDR output with Unity HDR disabled, matching window/backbuffer size and an eligible flight/KSC camera. Map, menu, VAB and active close-vessel rendering suspend FG; unsupported upscaling scenes use native AA. Heavy load can suspend FG after its completed-image timeout; select Off and re-enable to retry. There is no Ray Reconstruction.

For bugs, use **F10 → Issue ZIP**, review its contents, and attach it with reproduction steps. Nothing is uploaded automatically. See [architecture and validation limits](https://github.com/Michionlion/ReduxBetterAA/blob/v0.6.2/docs/architecture.md) for the complete contract.
