Better AA 0.6.2 improves terrain and water stability, adds FSR 3.1 Native AA, and now includes all required native libraries in the download.

## What's changed

- Fixed flicker on water and distant coastlines with TAA, DLAA and FSR.
- Improved terrain stability during camera movement.
- Added modern FSR Native AA. The settings menu shows the FSR version available
  on your system (FSR 4.1 support is not well tested).
- Restored temporal AA sampling in map view while keeping map icons clear.
- Made TAA the default for new installs.
- Fixed settings changes occasionally repeating or reverting.

## Install or update

Download **one** ZIP for your installed Redux version:

| Redux version | Download |
| --- | --- |
| 0.2.9.0/SNAPSHOTs | [ReduxBetterAA-0.6.2-Redux-0.2.9.0.zip](https://github.com/Michionlion/ReduxBetterAA/releases/download/v0.6.2/ReduxBetterAA-0.6.2-Redux-0.2.9.0.zip) |
| 0.2.8.5 | [ReduxBetterAA-0.6.2-Redux-0.2.8.5.zip](https://github.com/Michionlion/ReduxBetterAA/releases/download/v0.6.2/ReduxBetterAA-0.6.2-Redux-0.2.8.5.zip) |

Close the game and extract the ZIP beside `KSP2_x64.exe`. For an update, move the old `mods/ReduxBetterAA` folder outside `mods` first, then restore only your configuration.

Choose an anti-aliasing mode in **Settings → Mods → Redux Better AA**.

## Known limitations

- Most testing has been on Redux 0.2.9.0 with an RTX 5070 Ti. AMD hardware, FSR 4, Redux 0.2.8.5 and long sessions need more testing. DLAA requires a supported RTX GPU.
- Supersampling switches to Off while in the map and main menu.
- F10's live A/B view can affect terrain appearance; close it when checking normal gameplay.

For a rendering problem, use **F10 → Issue ZIP**, review its images, and attach it with reproduction steps to an [issue](https://github.com/Michionlion/ReduxBetterAA/issues).
