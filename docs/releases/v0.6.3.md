Public release candidate for native anti-aliasing and supersampling. Experimental
v0.6.2 was withdrawn; upscaling and frame generation remain on the
[investigation branch](https://github.com/Michionlion/ReduxBetterAA/tree/investigate/upscaling-frame-generation).

Download one complete ZIP matching Redux 0.2.9.0 (Unity 6000.5.8f1) or Redux
0.2.8.5 (Unity 6000.4.1f1). It contains the mod, required native libraries,
licenses and a complete payload manifest. Extract beside `KSP2_x64.exe` with
the game closed. Move the old mod folder outside `mods` first; restore only
configuration and reports, not old native libraries.

- Retains terrain motion repair and coherent transparent jitter that stabilized
  the tested distant coastline/water view, plus earlier terrain-depth, map-icon
  and foliage fixes. Terrain motion observation requires the inspected newer engine;
  unsupported renderer contracts retain ordinary motion.
- TAA remains the default. DLAA, modern FSR Native AA, FXAA, SMAA, supersampling
  and Off remain available according to runtime capabilities. FSR uses native
  resolution and reports the provider selected by the SDK.
- Removes upscaling/frame-generation controls and their capture/presentation hooks.
  Saved experimental AA modes fall back to Off; supported AA settings persist.
- Retains deferred settings normalization to avoid recursive Redux UI callbacks,
  per-frame report provenance and improved GPU timing diagnostics.

Validation on Redux 0.2.9.0.104521 / Unity 6000.5.8f1, D3D11, RTX 5070 Ti:

- A fresh checkout built successfully with 209 EditMode tests and 31 portable
  release/package checks. Both complete archives passed engine, contents and hash validation.
- The native AMD bridge rebuilt and passed its synthetic GPU interop, exposure,
  motion/jitter, reset and retirement tests; the active provider was FSR 3.1.5.
- The separated rendering implementation at commit `6eb0aa3` passed 94 player
  assertions and 69 validated diagnostic captures at 1920x1080: 35 without vendor
  libraries, then 34 with the complete ZIP. DLAA and FSR 3.1 ran in menu, flight
  and map; mode changes, Off, supersampling, reload, unpaused flight and Issue ZIPs
  were checked. Later changes only clarify missing-library messages and validation notes.
- The test used a fresh mod install in an existing disposable Redux player. The
  full stock-game-to-Redux updater pipeline was not repeated. The original profile
  was restored; test files remained outside the source checkout.

Earlier moving coastline tests covered TAA, DLAA and FSR on this GPU at 1440p;
the user reported no visible flicker. That evidence predates this separation.
Before publishing, review moving-image quality and the retained UI screenshots.
AMD FSR 4, non-NVIDIA hardware, the older Redux player and broad long-session
stability remain unvalidated; the older engine archive is hash-verified, not
in-game certified by this run. There is no new performance claim.

For a rendering problem, use F10 → Issue ZIP, review the captured images, and
attach the ZIP with reproduction steps. Nothing uploads automatically.
