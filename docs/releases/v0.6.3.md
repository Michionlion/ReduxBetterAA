Better AA 0.6.3 supports Redux snapshot 26w39b and its Unity 6000.6.0f1 engine.

- Restores terrain and foliage motion repairs on the new snapshot.
- Updates the foliage repair shader and included NVIDIA integration for the new engine.
- Keeps a separate download for Redux 0.2.8.5.
- Reduces TAA star shimmer, with steadier background history and clearer moving stars.
- Improves TAA color clipping and rejection of old foreground color when the sky becomes visible.

Close the game and extract the ZIP beside `KSP2_x64.exe`. Move the old
`mods/ReduxBetterAA` folder outside `mods` first, then restore your configuration.

| Redux version | Download |
| --- | --- |
| 0.2.9.0 snapshot 26w39b (Unity 6000.6.0f1) | `ReduxBetterAA-0.6.3-Redux-0.2.9.0.zip` |
| 0.2.8.5 | `ReduxBetterAA-0.6.3-Redux-0.2.8.5.zip` |

Both downloads include the native libraries. Older Unity 6000.5.8f1 snapshots
need Better AA 0.6.2. AMD hardware, FSR 4 and long sessions need more testing.
